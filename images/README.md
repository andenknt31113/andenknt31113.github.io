# 投稿用画像の置き場所

このフォルダに置いた画像が、そのまま Google ビジネスプロフィールの投稿画像になります。

## 置き方

1. このフォルダに画像をアップロードする（`.jpg` / `.jpeg` / `.png`）
2. ファイル名は **並び順がそのまま投稿順** になるので、数字を頭に付けるのがおすすめ

```
images/
  01.jpg
  02.jpg
  03.jpg
  ...
  60.jpg
```

## ルール

- **ファイル名は半角英数字にしてください。** 日本語ファイル名でも動きますが、URL が長くなりトラブルの元です。
- 画像は名前順に並べ、本文パターンと同じ番号どうしが組み合わさります
  （パターン1 → 1番目の画像、パターン2 → 2番目の画像 …）。
- **画像の枚数は60枚でなくても構いません。** 例えば20枚なら、パターン21では1枚目に戻って使い回します。
- 画像が1枚もない場合は、テキストのみで投稿されます。
- Google の推奨サイズは 720×720px 以上、10KB〜5MB、JPG または PNG です。

## 特定のパターンだけ別の画像を使いたい場合

`content/posts.json` の該当パターンに `"imageUrl"` を足すと、そのパターンだけ指定した
URL の画像が使われます。

```json
{
  "id": 7,
  "topic": "レディースカット",
  "summary": "【レディースカット】…",
  "imageUrl": "https://andenknt31113.github.io/images/ladies-special.jpg"
}
```
