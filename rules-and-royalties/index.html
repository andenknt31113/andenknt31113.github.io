1. 30 秒でわかる OFC パイナップルの進行ルール

  • 3 段（13 枚）のボードを作る：トップ 3 枚・ミドル 5 枚・ボトム 5 枚にカードを配置します。
  • 初手（ストリート 0）：配られた 5 枚をすべて好きな段に配置します（捨て札なし）。
  • 2〜5 巡目（ストリート 1〜4）：毎回 3 枚引き、2 枚を配置・1 枚を裏向きで捨てるを 4 回繰り返して計 13 枚を完成させます。
  • 絶対条件（ファウル禁止）：完成時に ボトム ≥ ミドル ≥ トップ の強さ順になっていなければなりません。逆転するとファウル（バースト）となり、自分の役とロイヤリティがすべて無効になります。

2. ロイヤリティ点数表（完全版）

ロイヤリティは「特定の強い役を作ったときにもらえるボーナス点」です。ファウルしていなければ、その段で負けていても自分のロイヤリティは加算されます。

3. スコア清算・スクープ・ファウルの計算方法

通常清算（両者ファウルなし）

① 行ポイント：トップ・ミドル・ボトムをそれぞれ比較し、勝った段ごとに +1 pt（引き分け 0 pt）。
② スクープボーナス：3 段すべて勝つとさらに +3 pt（行ポイントと合わせて +6 pt）。
③ ロイヤリティ差：「自分のロイヤリティ合計 − 相手のロイヤリティ合計」を加算します。

ファウル（バースト）時の清算

片方がファウルすると、ファウル側のロイヤリティは 0 点になり、正常側の スクープ勝ち（+6 pt）＋ 正常側のロイヤリティ全額 を支払います。
両者ともファウルした場合は 0 pt（引き分け） です。

4. ファンタジーランド（FL）突入・継続条件と期待値

  • 突入条件：通常局でファウルせずにトップへ QQ 以上 を作ると、次局は手札を一括配布される「ファンタジーランド」に突入します（QQ=14枚 / KK=15枚 / AA=16枚 / Trips=17枚）。
  • 継続（リファンタジー）条件：ファンタジー局でファウルせずに「トップでスリーカード」または「ボトムでフォーカード以上」を作ると、次局もファンタジーが継続します。
  • 54 枚（ジョーカー 2 枚）vs 52 枚（ジョーカーなし）：ジョーカー入りではワイルドカードにより継続率が大きく跳ね上がります（例：スタック無限の Trips 17枚 FL は 54枚で 126.4 pt、52枚では 58.5 pt）。

実効スタック（50pt / 100pt / 200pt / ∞）や 54枚 vs 52枚でファンタジー期待値がどれくらい変わるかの実測データは、 ファンタジーランド期待値表ガイド で詳しく公開しています。

5. ジョーカー（ワイルドカード）の扱い

54 枚ルールではジョーカー 2 枚が任意のカード（既に盤面にあるカードと同じスート・ランクを含む）として機能します。また、ある段でジョーカーを最も強い役として読むと上の段より弱くなってファウルしてしまう場合でも、ファウルを回避できる最も強い合法役へ自動的に降格して評価されます。
