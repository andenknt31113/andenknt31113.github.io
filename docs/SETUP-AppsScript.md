# ZER01 barber & lounge｜Google ビジネスプロフィール 自動投稿（スプレッドシート版）

Googleスプレッドシートに投稿を並べておくと、**投稿予定日が来た日に自動で1件ずつ投稿**されます。
費用は0円。すべてGoogleアカウントの中で完結し、GitHubもプログラムの知識も必要ありません。

日々の運用は「スプレッドシートを見る・直す」だけです。

- **A. 初期設定（1回だけ・少し手間がかかります）** … 設定担当の方向け
- **B. ふだんの使い方** … 店舗のオーナー・スタッフさん向け

# A. 初期設定（1回だけ）

## A-1. Google に API の利用申請をする ★最初にやること

Googleビジネスプロフィールへ自動で投稿するには、Googleの審査を1回通す必要があります。
**申請は無料**ですが、[審査に最大14日かかります](https://developers.google.com/my-business/content/prereqs)。
先に出しておいて、待っている間に A-2 以降を進めてください。

### 申請の条件

- 認証済みで **60日以上運用しているビジネスプロフィール**（ZER01さんは該当します）
- **事業用のWebサイト**があること
- ビジネスプロフィールのオーナー権限を持つGoogleアカウント

### 手順

1. [Google Cloud Console](https://console.cloud.google.com/) にログインし、プロジェクトを新規作成
   （名前は `zer01-gbp-post` など何でも構いません）
2. 作成したプロジェクトの **プロジェクト番号** を控える（ダッシュボードに表示されます）
3. 「APIとサービス > ライブラリ」で次を有効化
   - My Business Account Management API
   - My Business Business Information API
4. [Business Profile API の利用申請フォーム](https://developers.google.com/my-business/content/prereqs)
   から **Application For Basic API Access** を送信

> [新しいプロジェクトは必ず割当（クォータ）0＝使用不可の状態から始まります](https://developers.google.com/my-business/content/limits)。
> 承認されると 300 QPM になります。「APIとサービス > 割り当て」で確認できます。

## A-2. スプレッドシートを用意する

1. Googleドライブで新しいスプレッドシートを作成し、名前を `ZER01 GBP自動投稿` などにする
2. シート名（左下のタブ）を **`投稿一覧`** に変更する ← この名前でないと動きません
3. 「ファイル > インポート > アップロード」から `ZER01_投稿一覧.csv` を選び、
   **インポート場所は「現在のシートを置換する」** を選択
4. B列（投稿予定日）を選択し、「表示形式 > 数字 > 日付」を適用

これで1行目が見出し、2行目以降に60件の投稿が入った状態になります。

| 列 | 内容 |
|---|---|
| A | No |
| B | 投稿予定日 ← **この日付が来たら投稿されます** |
| C | 曜日 |
| D | トピック |
| E | 本文 |
| F | 画像URL（次の手順で自動入力されます） |
| G | 投稿済み |
| H | 投稿日時 |
| I | 結果・エラー |

## A-3. 画像をGoogleドライブに置く

1. Googleドライブに画像用のフォルダを作る（例: `ZER01 投稿画像`）
2. 投稿に使う画像をアップロードする
   - ファイル名は `01.jpg`, `02.jpg` … のように**番号を付けると並び順どおりに割り当たります**
   - 60枚なくても構いません。足りない分は先頭から使い回します
   - Google推奨は 720×720px以上、10KB〜5MB、JPGまたはPNG

## A-4. スクリプトを貼り付ける

1. スプレッドシートのメニューから「拡張機能 > Apps Script」を開く
2. 最初から入っている `myFunction` のコードを**全部消して**、`apps-script/Code.gs` の中身を貼り付ける
3. 左側の歯車「プロジェクトの設定」を開き、
   - 「`appsscript.json` マニフェスト ファイルをエディタで表示する」に**チェックを入れる**
   - 「Google Cloud Platform（GCP）プロジェクト」の**「プロジェクトを変更」**を押し、
     A-1で作った**プロジェクト番号**を入力して設定する ← ここが最重要
4. エディタに現れた `appsscript.json` を、`apps-script/appsscript.json` の中身に置き換える
5. 保存（フロッピーのアイコン）

## A-5. 動かして承認する

1. スプレッドシートを**開き直す**と、メニューバーに **「GBP自動投稿」** が追加されます
2. 「GBP自動投稿 > ② 画像をドライブから読み込む」を実行
   - 初回はGoogleの承認画面が出ます。「詳細 > （プロジェクト名）に移動」→「許可」
   - 「このアプリは確認されていません」と出ますが、自分で作ったスクリプトなので問題ありません
   - A-3で作ったフォルダのURLを貼り付けると、F列に画像URLが入り、画像の共有設定も自動で
     「リンクを知っている全員が閲覧可」に変更されます
3. 「① 店舗ID・アカウントIDを設定」で、次の手順で調べたIDを入力

### アカウントID・店舗IDを調べる

[OAuth 2.0 Playground](https://developers.google.com/oauthplayground/) を開き、
左の欄に `https://www.googleapis.com/auth/business.manage` を貼って
**Authorize APIs** →ログイン→ **Exchange authorization code for tokens**。
表示された Access token を使って、同じ画面の右上「Enter request URI」に以下を順に入力し Send:

```
https://mybusinessaccountmanagement.googleapis.com/v1/accounts
```
→ 返ってきた `"name": "accounts/123456789012345"` の数字部分が**アカウントID**

```
https://mybusinessbusinessinformation.googleapis.com/v1/accounts/123456789012345/locations?readMask=name,title
```
→ ZER01 barber & lounge の `"name": "locations/987654321098765"` の数字部分が**店舗ID**

## A-6. テストして自動投稿をオンにする

1. 「③ 内容をチェックする」→「問題は見つかりませんでした」と出ればOK
2. 「次の投稿内容を確認（投稿しない）」で、投稿される文章と画像を確認
3. 「今すぐ1件投稿する」で1件だけ実戦テスト。ビジネスプロフィールに出れば成功
   - 失敗した場合はI列に日本語のエラーが入ります（下の「困ったとき」参照）
4. 「毎日の自動投稿をオンにする」を実行 → **完了です**

以降は毎日10時台にスクリプトが動き、投稿予定日を迎えた行を1件投稿します。

# B. ふだんの使い方（オーナー・スタッフさん向け）

普段は**何もしなくて大丈夫**です。気になったときにスプレッドシートを開いてください。

## いま何が起きているか見る

「GBP自動投稿 > 自動投稿の状態を確認」で、オン/オフ・投稿済み件数・次の投稿が分かります。
シート上でも、投稿が終わった行はG列に「済」、H列に投稿日時が入ります。

## 文章を直したい

E列（本文）を直接書き換えるだけです。まだ「済」が付いていない行なら、その内容で投稿されます。

## 投稿する日をずらしたい・お休みしたい

B列（投稿予定日）の日付を変えてください。行ごと削除しても構いません。
**まるごと止めたいときは**「毎日の自動投稿をオフにする」を実行してください。

## 画像を差し替えたい

Googleドライブのフォルダの画像を入れ替えてから、
「② 画像をドライブから読み込む」をもう一度実行すればF列が入れ替わります。
1行だけ変えたいときは、その行のF列に画像URLを直接貼っても構いません。

## 投稿を追加したい

一番下の行に、A〜F列（No / 投稿予定日 / 曜日 / トピック / 本文 / 画像URL）を書き足すだけです。
本文は1500文字までです。書き足したら「③ 内容をチェックする」を実行してください。

## 60件を投稿し終わったら

2日おきなので約4か月で一巡します。B列の日付を新しい日付に直し、G〜I列（投稿済み・投稿日時・
結果）を空にすれば、同じ60件をもう一巡使えます。文章を少し変えると、より効果的です。

# 困ったとき

投稿に失敗すると、その行のI列に日本語でエラーが記録されます。

| I列に出るもの | 対処 |
|---|---|
| `APIエラー 403: APIの利用が許可されていません` | A-1の申請がまだ承認されていないか、A-4の手順3でGCPプロジェクトの紐付けができていません |
| `APIエラー 401` | Apps Scriptを開いて任意のメニューを実行し、承認をやり直してください |
| `APIエラー 404` | 「① 店舗ID・アカウントIDを設定」を、A-5の手順でやり直してください |
| `APIエラー 429` | 一時的な回数制限です。翌日には自動で再開します |
| `画像を取得できません` | ドライブの画像が「リンクを知っている全員が閲覧可」になっていません。「② 画像をドライブから読み込む」を再実行してください |
| `本文が◯◯文字で上限を超えています` | E列の本文を1500文字以内に縮めてください |
| 何も起きない | 「自動投稿の状態を確認」でオンになっているか、B列の日付が未来になっていないか確認 |

## 投稿の文章について（申し送り）

いただいたWordファイルは「60パターン」でしたが、中身は**20パターンが3回繰り返された状態**
でした（投稿1＝21＝41 …）。Googleは同一本文を重複と判定することがあるため、
No.1〜20は原文のまま、No.21〜40とNo.41〜60は同じトピック・同じ情報のまま言い回しを変えた版に
差し替えてあります。店舗情報・料金・キャンペーンなど、原文にない事実は足していません。
